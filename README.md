# Laser Weave ✨

Laser Weave is an interactive browser experiment that uses AI-powered hand tracking to turn your hand movements into glowing laser patterns.

Built with JavaScript, HTML5 Canvas, and MediaPipe Hands, it tracks both hands in real time and triggers colorful particle bursts when fingertips touch.

## Tech Stack
- JavaScript
- HTML5 Canvas
- MediaPipe Hands
- WebRTC

## Run Locally
1. Clone the repository
2. Open `cats_cradle.html`
3. Enable your camera
4. Start interacting

Built out of curiosity to explore computer vision and creative coding.
